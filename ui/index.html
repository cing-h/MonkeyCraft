            Google (for the Clerk)

            One-time setup (about 10 minutes)
            1. Open Google Cloud: new project, name it MonkeyCraft, and press Create.
            2. Turn on the four APIs (press Enable on each): Drive, Docs, Sheets, Slides.
            3. Open Google Auth Platform and press Get started. App name MonkeyCraft, your email for both email boxes, audience External.
            4. Under Audience, add yourself as a test user. (Optional: press Publish app so you don't have to reconnect every 7 days. MonkeyCraft only asks for its own files, so Google doesn't need to review it.)
            5. Under Clients, press Create client, choose Desktop app, name it MonkeyCraft, then Download JSON.
            6. Open that file in Notepad, copy everything, paste it below and press Save key. Then press Connect Google.
            So the Clerk can open your existing files (2 more minutes)
            1. Turn on the Google Picker API (press Enable).
            2. Open Credentials, press Create credentials → API key. Under API restrictions choose Restrict key and tick only Google Picker API, then save.
            3. Copy the key (it starts with AIza), paste it below and press Save picker key.

            MonkeyCraft only asks for access to the files it makes itself. It can never share files or delete them outright, and every change asks you first.
